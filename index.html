HOW I WORK

TEAMWORK

Every project here was built with other people, in teams of two or three, splitting the work across data, model and application layers.

COMMUNICATION

I write the technical reports and the API documentation so someone else can follow the work, check it and pick it up.

PROBLEM SOLVING

When the activity data was imbalanced, my team cut 11 classes down to 4 and improved the features instead of forcing the model.

DELIVERY AND LEARNING

I work with real clients, like INNLAB, and ship in sprints. I move between Java, Python and TypeScript, and between back end, machine learning and cloud, as each project asks.

What sets me apart

I like the whole path, from the idea to something running. I can train and explain a model, build the API and the interface around it, deploy it, and document each step so other people can trust the result.
